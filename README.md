# YouTube Clone

## Overview

A simple YouTube clone built using HTML and CSS to mimic the basic layout and design of YouTube.

## Features
- Responsive layout
- Header with logo and search bar
- Sidebar navigation menu
- Video grid with thumbnails and titles
- Footer section

## Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/vishnu-57/youtube-clone.git
   ```
2. Navigate to the project directory:
   ```bash
   cd youtube-clone
   ```
3. Open `index.html` in your browser.

## Usage
- Open `index.html` to view the YouTube clone interface.
- Modify `style.css` to customize the design.
